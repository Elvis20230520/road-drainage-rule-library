# 参数样板

全库唯一的一份参数样板（`参数样板.xlsx`），后续更新只改这个文件。当前含七张表：

- `路面排水-PS-001`（排水分项参数；与规则编号 PS-001 对应）
- `标志牌-JA-001`（交通标志，交安）
- `标线-JA-002`（路面标线，交安）
- `波形护栏-JA-003`（波形护栏，交安）
- `百米桩，里程碑-JA004`（百米桩，里程碑，交安 JA-004；表名没有连字符）
- `防眩板-JA-006`（防眩板，交安）
- `隔离栅、防落物网-JA-007`（隔离栅、防落物网，交安）

生成时给出规则库、「按编号 JA-001 / JA-002 / JA-003 / PS-001 去执行，项目编号 xxx」和本机必要文件路径。JA-004、JA-006、JA-007 已有草稿规则和上表三张工作表；本机脚本目前还不能按这三个编号出表。该路径里没有同名文件时，就用这一份；有同名则可本地覆盖。样例目录 `ja-params-sample-001/` 只示范 JA-001、JA-002、JA-003 的布局，不存放副本。各编号按自己的资料参数执行说明填写；说明要求看图而图不在指定路径里时，先列缺项，不臆造。
