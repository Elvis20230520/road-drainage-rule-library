# 样例 001

本目录是 **样例** 输入，用来试跑 JA-001 / JA-002 / JA-003。它不是正式成果，也不能代替 `docs/01-分项规则/02-交安工程/` 里的草稿规则。

台账表头仍保留源文件中的项目字样，只为保持和本机目录相同的文件布局。不要把这里的测站坐标或台账原文当成可对外引用的成果。

## 目录里有什么

- `资料台账-JA-001.xlsx`
- `资料台账-JA-002.xlsx`
- `资料台账-JA-003.xlsx`
- `导线点及水准点.xlsx`
- `资料参数执行说明-JA-001.md`
- `资料参数执行说明-JA-002.md`
- `资料参数执行说明-JA-003.md`

参数样板走仓库 share/，本地可覆盖放同名文件；后续更新只改 share/ 那一份。

本目录故意不放 `参数样板.xlsx`。

## 试跑

在仓库根目录：

```text
pip install -r tools/ja_params/requirements.txt
python -m tools.ja_params run JA-001 JA-002 JA-003 --project 001 --data-dir share/ja-params-sample-001
```

也可以只跑一个编号，例如 `run JA-001 --project 001 --data-dir share/ja-params-sample-001`。

结果写到本目录的 `output/`。该目录已被忽略，需要结果时在本机重新运行。JA-003 执行说明里的「标线-JA-003」是原文笔误，输出文件名仍是 `波形护栏-JA-003-001.xlsx`。
