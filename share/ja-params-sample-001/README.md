# 样例 001

本目录是 **样例**，用来看 JA-001 / JA-002 / JA-003 的文件怎么摆。它不是默认的本机路径，也不是正式成果，不能代替 `docs/01-分项规则/02-交安工程/` 里的草稿规则。规则库里另有草稿 JA-004、JA-006、JA-007，参数样板已是七张表；本目录没有这三份的台账和执行说明。

正式执行时，本机另给台账、导线点及水准点和执行说明所在的路径。只有当次明确把路径指到这里，才会用到这套样例。

台账表头仍保留源文件中的项目字样，只为对照真实项目目录里的文件名。

## 怎么吩咐

每次三件事。本机必要文件路径写成当场给出的目录。要试本样例时，把路径指到本目录；做正式项目时写成那个项目的路径。

```text
规则库：https://github.com/Elvis20230520/road-drainage-rule-library
按编号 JA-001 去执行，项目编号 001
本机必要文件路径：<当次指定的绝对路径或本机路径>
```

三个编号：

```text
按编号 JA-001、JA-002、JA-003 去执行，项目编号 001
```

## 目录里有什么

- `资料台账-JA-001.xlsx`
- `资料台账-JA-002.xlsx`
- `资料台账-JA-003.xlsx`
- `导线点及水准点.xlsx`
- `资料参数执行说明-JA-001.md`
- `资料参数执行说明-JA-002.md`
- `资料参数执行说明-JA-003.md`

参数样板走仓库 share/，本地可覆盖放同名文件；后续更新只改 share/ 那一份。

填表以各编号的资料参数执行说明为准。说明要求看图纸时要读图；缺图先列缺项，不臆造。本样例三份说明以台账、测点和样板为主。

本目录不放 `参数样板.xlsx`。结果写到本目录的 `output/`，该目录已被忽略。JA-003 执行说明里的「标线-JA-003」是原文笔误，输出文件名仍是 `波形护栏-JA-003-001.xlsx`。

正式项目使用当次给出的路径，文件名与上面相同，结果写入该路径的 `output/`。说明见 `tools/ja_params/README.md`。
