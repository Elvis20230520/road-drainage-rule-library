# 交安资料参数

JA-001 交通标志、JA-002 路面标线、JA-003 波形护栏。规则在 `docs/01-分项规则/02-交安工程/`，目前是草稿。

同目录还有草稿 JA-004 百米桩，里程碑、JA-006 防眩板、JA-007 隔离栅、防落物网。编号不是连号，没有 JA-005。参数样板已有对应的三张表。本脚本目前只生成 JA-001、JA-002、JA-003；吩咐里写了后三个编号时不会改用别的表顶上。

## 主用法

每次给出三件事。本机必要文件路径由当次明确指定，样例目录不是默认路径。

1. 规则库仓库地址，或本机已经 clone、目录结构与本仓库相同的规则库。
2. 一句吩咐。单个编号：「按编号 JA-001 去执行，项目编号 001」。多个编号：「按编号 JA-001、JA-002、JA-003 去执行，项目编号 001」。可以另写「用线上文件」或「用本地文件」，二选一，决定执行说明读哪一侧。不写则按下面的默认。
3. 本机必要文件路径。这是台账、导线点及水准点所在的绝对路径或本机路径，每次单独给出。「用本地文件」或未写来源时，执行说明也放在这里。

示例：

```text
规则库：https://github.com/Elvis20230520/road-drainage-rule-library
按编号 JA-001 去执行，项目编号 001
本机必要文件路径：D:\资料\某项目
用线上文件
```

最后一行换成「用本地文件」，就改读该路径里的同名执行说明。这一行可以不写。两句同时写时，脚本拒绝执行。

三个编号一起做时，第 2 行换成「按编号 JA-001、JA-002、JA-003 去执行，项目编号 001」，路径仍是当次给出的那个目录。

编号决定做哪张参数表，项目编号写进输出文件名。结果写在该路径下的 `output/`。

## 参数样板

参数样板只有仓库里的 `share/参数样板.xlsx` 这一份，以后也只在这里更新。现为七张表：`路面排水-PS-001`、`标志牌-JA-001`、`标线-JA-002`、`波形护栏-JA-003`、`百米桩，里程碑-JA004`、`防眩板-JA-006`、`隔离栅、防落物网-JA-007`。本脚本只读取前三张交安表。JA-004 的表名没有连字符。

查找顺序：

1. `{本机必要文件路径}/参数样板.xlsx`，这个路径里放了同名文件才用。
2. 否则用仓库 `share/参数样板.xlsx`。

某个项目要临时换一版，把同名文件放进当次指定的路径，只影响这一次。仓库里不另存第二份。

## 执行说明与图纸

每个编号的填表依据是同名的 `资料参数执行说明-JA-xxx.md`。脚本从中解析 D、E、F；JA-002 还会解析 AD、AE、AF。工作表名、输出文件名、测站匹配和 B 列清洗不从这份说明改写，仍用脚本内置规则。

执行说明在执行时二选一：

| 吩咐 | 只读这一侧 | 不读的另一侧 |
|---|---|---|
| 「用线上文件」 | 规则库 `share/ja-params-sample-001/资料参数执行说明-JA-xxx.md` | 本机必要文件路径里的同名文件 |
| 「用本地文件」 | `{本机必要文件路径}/资料参数执行说明-JA-xxx.md` | 规则库里的同名文件 |
| 两句都没写 | 只查 `{本机必要文件路径}/资料参数执行说明-JA-xxx.md`。有文件就按文件解析 | 不读规则库。没有文件时，D/E/F 与常量使用内置规则 |

「不用线上文件」「不用本地文件」不会被当成选定那一侧。选定的一侧没有这份说明时，不改到另一侧去找，D/E/F 与常量使用内置规则，生成报告里会写明没读到文件。

规则库里现有的执行说明和样例台账放在同一目录。「用线上文件」只取其中的 `资料参数执行说明-JA-xxx.md`。台账、导线点及水准点、输出目录仍用当次的本机必要文件路径。样例目录不是数据目录的默认位置。

本脚本不读取 `docs/01-分项规则/02-交安工程/` 里的分项规则 Markdown，也不读取本机目录里同名的规则页。这些页面给人查阅。因此「用线上文件」和「用本地文件」只切换 `资料参数执行说明-JA-xxx.md`，没有第二套规则文件要一起换。参数样板也不跟着这两句走，仍是本机同名文件优先，否则 `share/参数样板.xlsx`。

说明要求看图纸，或某个字段离开图纸就填不上时，要读指定路径里的图纸。图纸不在该路径中，先把缺的图列出来，相关格子留空，不凭空补数。

JA-001、JA-002、JA-003 现行说明正文写的是资料台账、导线点及水准点和参数样板，就按这三份说明填。JA-004、JA-006、JA-007 的现行说明同样以这三份为主，规则页已整理，本脚本尚未执行。别的编号或以后改过的说明若写了图纸，按那份说明另读图。

## 指定路径里的文件

当次路径里按要做的编号放置文件。`share/ja-params-sample-001/` 示范下面这种摆法，执行时不把它当成默认数据目录。「用线上文件」只读取该目录中的执行说明。

```text
本机必要文件路径/
├─ 资料台账-JA-001.xlsx
├─ 资料台账-JA-002.xlsx
├─ 资料台账-JA-003.xlsx
├─ 导线点及水准点.xlsx
├─ 资料参数执行说明-JA-001.md    「用本地文件」或未写来源时在这里找；可以没有
├─ 资料参数执行说明-JA-002.md    「用线上文件」时这三份都不读
├─ 资料参数执行说明-JA-003.md
└─ output/                       生成后出现在这里
```

| 文件 | 作用 |
|---|---|
| `资料台账-JA-00x.xlsx` | 工作表 `交安工程-JA-00x`，从第 4 行读 B 列 |
| `导线点及水准点.xlsx` | 工作表 `导线点`、`水准点` |
| `资料参数执行说明-JA-00x.md` | 该编号的填表依据。可「用线上文件」或「用本地文件」。未写时，本机有则用本机，没有则用内置规则。JA-002 的 AD/AE/AF 也从读到的说明解析 |
| `output/` | 参数表、生成报告、缺测站清单。可以重新生成，不放进规则库 |

输出文件名：

| 编号 | 参数表 |
|---|---|
| JA-001 | `output/标志牌-JA-001-{项目编号}.xlsx` |
| JA-002 | `output/标线-JA-002-{项目编号}.xlsx` |
| JA-003 | `output/波形护栏-JA-003-{项目编号}.xlsx` |

每份参数表旁边还有同名的 `-生成报告.txt` 和 `-缺测站清单.xlsx`，以及 `output/生成汇总.txt`。缺测站的行整行黄底。JA-003 执行说明里的「标线-JA-003」按原文笔误处理，文件名仍用「波形护栏-JA-003」。

规则页里另外三个输出名，脚本尚未生成：

| 编号 | 参数表 |
|---|---|
| JA-004 | `output/百米桩，里程碑-JA004-{项目编号}.xlsx` |
| JA-006 | `output/防眩板-JA-006-{项目编号}.xlsx` |
| JA-007 | `output/隔离栅、防落物网-JA-007-{项目编号}.xlsx` |

## 测站

邻近上限 2000 米。互通只认全称：白岭互通、石坳互通、港口互通、修水西枢纽、铜鼓枢纽。有桩号时在走廊池内匹配；无桩号但有全称时，用该走廊主线 K 中位数在池内取点。没有 3 公里兜底。间距、左右幅和留空列见对应规则页。

## 内部 / 本机脚本

上面的吩咐由本机脚本执行，依赖 `openpyxl`：

```text
pip install -r tools/ja_params/requirements.txt
```

在规则库根目录，把吩咐解析成参数。`--data-dir` 就是当次给出的本机必要文件路径：

```text
python -m tools.ja_params parse "按编号 JA-001 去执行，项目编号 001"
python -m tools.ja_params parse "按编号 JA-001 去执行，项目编号 001。用线上文件"
python -m tools.ja_params run --order "按编号 JA-001 去执行，项目编号 001。用本地文件" --data-dir "D:\资料\某项目"
python -m tools.ja_params run --order "按编号 JA-001 去执行，项目编号 001" --data-dir "D:\资料\某项目"
python -m tools.ja_params run JA-001 --project 001 --data-dir "D:\资料\某项目"
python -m tools.ja_params run JA-001 JA-002 JA-003 --project 001 --data-dir "D:\资料\某项目"
```

吩咐里如果已经写了「本机必要文件路径：...」，`parse` 会把该路径放进 `--data-dir`。`run` 在命令行上写了 `--data-dir` 时用命令行这一条。

吩咐里写了「用线上文件」或「用本地文件」时，`parse` 会多打出 `--instruction-source online` 或 `--instruction-source local`。`run` 也可以直接带这个参数，`online` 就是用线上文件，`local` 就是用本地文件。命令行和吩咐不一致时拒绝执行。不写来源时不传这个参数。

`share/ja-params-sample-001` 只用于看文件名怎么摆。要拿它试跑，也要把这个路径当次写出来，它不是缺省目录。
