# 交安资料参数生成

在仓库根目录按分项编号生成本地参数表。适用 JA-001 交通标志、JA-002 路面标线、JA-003 波形护栏。规则正文在 `docs/01-分项规则/02-交安工程/`，状态为草稿。这里只是按规则填表的脚本。

## 安装

```text
pip install -r tools/ja_params/requirements.txt
```

依赖 `openpyxl`。

## 用法

在仓库根目录执行：

```text
python -m tools.ja_params run JA-001 --project 001 --data-dir share/ja-params-sample-001
python -m tools.ja_params run JA-002 --project 001 --data-dir share/ja-params-sample-001
python -m tools.ja_params run JA-003 --project 001 --data-dir share/ja-params-sample-001
python -m tools.ja_params run JA-001 JA-002 JA-003 --project 001 --data-dir share/ja-params-sample-001
```

`--project` 写入输出文件名。`--data-dir` 是本机项目目录，布局与样例一致即可。

## 数据目录

| 文件 | 是否必须 | 作用 |
|---|---|---|
| `资料台账-JA-001.xlsx` / `JA-002` / `JA-003` | 跑哪个编号就要哪一份 | 工作表名为 `交安工程-JA-00x`，从第 4 行读 B 列 |
| `导线点及水准点.xlsx` | 是 | 工作表 `导线点`、`水准点` |
| `资料参数执行说明-JA-00x.md` | 否 | 有则读取。能解析时采用其中的 D/E/F；JA-002 还可解析 AD/AE/AF。没有则用内置规则 |
| `参数样板.xlsx` | 否 | 有则用这一份；没有则用仓库 `share/参数样板.xlsx` |

参数样板在仓库里只有 `share/参数样板.xlsx` 一份。后续更新只改这一份。某个项目要临时改表，把同名文件放进该项目的数据目录即可，不要在仓库里再存一份。

工作表名和输出文件名以内置规则为准。JA-003 的执行说明把表写成「标线-JA-003」，脚本仍使用「波形护栏-JA-003」。

## 输出

写到 `<data-dir>/output/`：

| 编号 | 参数表 | 报告 | 缺测站清单 |
|---|---|---|---|
| JA-001 | `标志牌-JA-001-{项目编号}.xlsx` | 同名 `-生成报告.txt` | 同名 `-缺测站清单.xlsx` |
| JA-002 | `标线-JA-002-{项目编号}.xlsx` | 同名 `-生成报告.txt` | 同名 `-缺测站清单.xlsx` |
| JA-003 | `波形护栏-JA-003-{项目编号}.xlsx` | 同名 `-生成报告.txt` | 同名 `-缺测站清单.xlsx` |

另有 `生成汇总.txt`。缺 2 个导线点或缺水准点的行，测站留空，整行黄底 `FFFF00`。

这些文件可以重新生成，不作为规则库内容。样例目录下的 `output/` 已被忽略。

## 测站匹配

- 邻近上限 2000 米。
- 台账 B 列只按全称锁互通走廊：白岭互通、石坳互通、港口互通、修水西枢纽、铜鼓枢纽。不使用「白岭」「修水西」等短名。
- 有桩号：先在走廊池内匹配，同前缀优先，再任意前缀，仍不超过 2000 米。池内不够时，改用该走廊主线 K 中位数，距离相对中位数仍不超过 2000 米。
- 无桩号但有互通全称：用走廊主线 K 中位数在池内取点，不套 2000 米。
- 没有互通全称：在全部测站中按同前缀优先、再任意前缀匹配，不超过 2000 米。
- 不启用 3 公里兜底。

桩号间距、左右幅和留空列见对应分项规则。
