# 交安资料参数

JA-001 交通标志、JA-002 路面标线、JA-003 波形护栏。规则在 `docs/01-分项规则/02-交安工程/`，目前是草稿。

## 主用法

每次给出三件事。本机必要文件路径由当次明确指定，样例目录不是默认路径。

1. 规则库仓库地址，或本机已经 clone、目录结构与本仓库相同的规则库。
2. 一句吩咐。单个编号：「按编号 JA-001 去执行，项目编号 001」。多个编号：「按编号 JA-001、JA-002、JA-003 去执行，项目编号 001」。
3. 本机必要文件路径。这是台账、导线点及水准点、执行说明所在的绝对路径或本机路径，每次单独给出。

示例：

```text
规则库：https://github.com/Elvis20230520/road-drainage-rule-library
按编号 JA-001 去执行，项目编号 001
本机必要文件路径：D:\资料\某项目
```

三个编号一起做时，第 2 行换成「按编号 JA-001、JA-002、JA-003 去执行，项目编号 001」，路径仍是当次给出的那个目录。

编号决定做哪张参数表，项目编号写进输出文件名。结果写在该路径下的 `output/`。

## 参数样板

参数样板只有仓库里的 `share/参数样板.xlsx` 这一份，以后也只在这里更新。三张表是 `标志牌-JA-001`、`标线-JA-002`、`波形护栏-JA-003`。

查找顺序：

1. `{本机必要文件路径}/参数样板.xlsx`，这个路径里放了同名文件才用。
2. 否则用仓库 `share/参数样板.xlsx`。

某个项目要临时换一版，把同名文件放进当次指定的路径，只影响这一次。仓库里不另存第二份。

## 指定路径里的文件

当次路径里按要做的编号放置文件。`share/ja-params-sample-001/` 只示范下面这种摆法，执行时不把它当成默认目录。

```text
本机必要文件路径/
├─ 资料台账-JA-001.xlsx
├─ 资料台账-JA-002.xlsx
├─ 资料台账-JA-003.xlsx
├─ 导线点及水准点.xlsx
├─ 资料参数执行说明-JA-001.md    可以没有
├─ 资料参数执行说明-JA-002.md
├─ 资料参数执行说明-JA-003.md
└─ output/                       生成后出现在这里
```

| 文件 | 作用 |
|---|---|
| `资料台账-JA-00x.xlsx` | 工作表 `交安工程-JA-00x`，从第 4 行读 B 列 |
| `导线点及水准点.xlsx` | 工作表 `导线点`、`水准点` |
| `资料参数执行说明-JA-00x.md` | 可选。能读出 D/E/F 时采用说明；JA-002 还可读出 AD/AE/AF |
| `output/` | 参数表、生成报告、缺测站清单。可以重新生成，不放进规则库 |

输出文件名：

| 编号 | 参数表 |
|---|---|
| JA-001 | `output/标志牌-JA-001-{项目编号}.xlsx` |
| JA-002 | `output/标线-JA-002-{项目编号}.xlsx` |
| JA-003 | `output/波形护栏-JA-003-{项目编号}.xlsx` |

每份参数表旁边还有同名的 `-生成报告.txt` 和 `-缺测站清单.xlsx`，以及 `output/生成汇总.txt`。缺测站的行整行黄底。JA-003 执行说明里的「标线-JA-003」按原文笔误处理，文件名仍用「波形护栏-JA-003」。

## 测站

邻近上限 2000 米。互通只认全称：白岭互通、石坳互通、港口互通、修水西枢纽、铜鼓枢纽。有桩号时在走廊池内匹配；无桩号但有全称时，用该走廊主线 K 中位数在池内取点。没有 3 公里兜底。间距、左右幅和留空列见对应规则页。

## 内部 / 本机脚本

上面的吩咐由本机脚本执行，依赖 `openpyxl`：

```text
pip install -r tools/ja_params/requirements.txt
```

在规则库根目录，把吩咐解析成参数。`--data-dir` 就是当次给出的本机必要文件路径：

```text
python -m tools.ja_params parse "按编号 JA-001 去执行，项目编号 001"
python -m tools.ja_params run --order "按编号 JA-001 去执行，项目编号 001" --data-dir "D:\资料\某项目"
python -m tools.ja_params run JA-001 --project 001 --data-dir "D:\资料\某项目"
python -m tools.ja_params run JA-001 JA-002 JA-003 --project 001 --data-dir "D:\资料\某项目"
```

吩咐里如果已经写了「本机必要文件路径：...」，`parse` 会把该路径放进 `--data-dir`。`run` 在命令行上写了 `--data-dir` 时用命令行这一条。

`share/ja-params-sample-001` 只用于看文件名怎么摆。要拿它试跑，也要把这个路径当次写出来，它不是缺省目录。
