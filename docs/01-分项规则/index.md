# 分项规则

分项规则按一级分类和二级分类存放。每个分项使用一个独立 Markdown 文件。

## 文件命名

```text
编号-分项名称.md
```

例如：

```text
FX-001-雨水口布置.md
```

## 管理要求

- 每个分项编号必须唯一。
- 文件移动或分项改名时同步更新 `分项总表.csv` 中的路径。
- 当前执行规则写在文件正文，历史变化写在文件末尾的“修改记录”。
- 复杂附件、示意图或大批案例可以建立与分项同名的附件目录。
- 不把具体项目的临时要求写入通用分项规则。

新建规则时，从仓库根目录的 `templates/分项规则模板.md` 复制。
