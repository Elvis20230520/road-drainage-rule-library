## 一、目标

从资料台账生成「波形护栏-JA-003」参数表。输出文件也使用这个名称，不使用说明里误写的「标线-JA-003」。

## 二、适用范围

- 台账工作表为 `交安工程-JA-003`，有效内容在 B 列。
- 参数样板工作表为 `波形护栏-JA-003`。
- B 列已写明位置的路侧护栏记录。

## 三、不适用范围

- 按说明笔误去找「标线-JA-003」工作表。
- 台账没有砼数量时自行估算 I 列。
- 3km 测站兜底，以及用互通短名锁池。

## 五、与执行说明不一致的地方

说明原文有两处不能照抄：

1. 表名写成「标线-JA-003」。样板和输出文件使用「波形护栏-JA-003」。
2. 第 10 条前面写 R、S、T，末尾又写成「只有一个桩号时 AA 和 AB 写上该桩号」。单桩号按 R=S、T=0 填写。

## 六、填写规则

表头两行从样板复制。数据从第 3 行起写。

| 列 | 规则 |
|---|---|
| A | 序号，从 1 起 |
| B | 台账 B 列。去掉开头的「波形护栏工程」和末尾左右侧用语 |
| C | 左幅或右幅。规则同 JA-001 |
| D、E、F | 交安工程、波形护栏、安全设施。执行说明解析结果不同时改用说明 |
| G、H | 留空 |
| I | 砼数量。台账没有来源时留空 |
| J 至 O | 不超过 2km 的两个导线点：点号、X、Y。小数 3 位 |
| P、Q | 不超过 2km 的一个水准点：点号、高程。小数 3 位 |
| R、S | 起止桩号，取整到 10 的整数 |
| T | 间距。见第七节 |
| U 至 W | 留空 |
| X | `=CONCATENATE("(",A行,")",B行,C行,E行)` |
| Y | 桩号前缀，如 K、AK、BK、CK |
| Z | `=CONCATENATE("(",A行,")",B行,C行,E行,"抽检")` |

## 七、桩号间距

与 JA-001 的分档相同，列是 R、S、T：

1. 起止桩号取整到 10。
2. 范围小于等于 50m 时 T 取 10；大于 50m 且小于等于 70m 时取 20；大于 70m 时取 40。
3. S 与 R 的差必须能被 T 整除。
4. 只有一个桩号时 R=S，T=0。
5. 没有桩号时 R、S、T 留空。

## 八、测站匹配

与 JA-001 相同。

邻近上限 2000m。只认全称：白岭互通、石坳互通、港口互通、修水西枢纽、铜鼓枢纽。

1. 有全称时只在该走廊池内选点。有桩号时不超过 2000m；池内不足则改用走廊主线 K 中位数，相对中位数仍不超过 2000m。
2. 无桩号但有全称时，用中位数在池内取点，不套 2000m。
3. 没有全称时走全局匹配，不超过 2000m。
4. 不启用 3km 兜底。

缺测站的数据行整行黄底 `FFFF00`。

## 十、边界条件和易错点

- 护栏台账里「改路两侧」没有单一左右侧。C 列可能留空或只能推断，以报告为准。
- 匝道桩号必须先按互通全称锁池。
- I 列不要用里程长度代替砼数量。
