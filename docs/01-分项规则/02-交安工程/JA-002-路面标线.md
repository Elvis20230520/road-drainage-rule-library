> 草稿。填表要求来自路面标线执行说明。测站匹配与 JA-001 相同：互通只锁全称，邻近上限 2km。确认前不用于正式成果。

## 一、目标

从资料台账生成「标线-JA-002」参数表，写明位置、左右幅、桩号间距和测站。台账没有的标线属性保持空白。

## 二、适用范围

- 台账工作表为 `交安工程-JA-002`，有效内容在 B 列。
- 参数样板工作表为 `标线-JA-002`。
- 主线、匝道、互通和枢纽中，B 列已写明位置的标线记录。

## 三、不适用范围

- 台账没有线段长度、宽度、颜色等属性时，凭经验补 I 至 R 列。
- 与当前参数样板列结构不一致的表。
- 3km 测站兜底，以及用互通短名锁池。

## 四、必要文件

| 文件或数据 | 是否必须 | 文件名 | 作用 | 缺失时处理 |
|---|---|---|---|---|
| 资料台账 | 是 | `资料台账-JA-002.xlsx` | 读取 B 列 | 停止 |
| 导线点及水准点 | 是 | `导线点及水准点.xlsx` | 工作表 `导线点`、`水准点` | 停止 |
| 参数样板 | 是 | `参数样板.xlsx` | 表头和列结构。数据目录没有时用仓库 `share/参数样板.xlsx` | 停止 |
| 执行说明 | 填表依据 | `资料参数执行说明-JA-002.md` | 本编号怎么填，以这份说明为准 | 没有说明时按本规则页中已整理的现行说明执行，并在报告中注明 |
| 设计图纸 | 说明要求时必须 | 放在当次指定路径中 | 说明写了要看图，或某字段没有图就填不上 | 先列入缺项，该字段留空，不臆造 |

参数样板在仓库中只保留 `share/参数样板.xlsx`。

现行说明要求阅读资料台账、导线点及水准点和参数样板。I 至 R 列说明写「按源表数据」，台账没有这些列，所以留空，不补造。说明若改为要看图纸，按说明读图。

## 五、填写规则

表头两行从样板复制。数据从第 3 行起写。

| 列 | 规则 |
|---|---|
| A | 序号，从 1 起 |
| B | 台账 B 列。去掉开头的「标线工程」和末尾左右侧用语。词尾「左线」「右线」与「左侧」「右侧」同剥 |
| C | 左幅或右幅。规则同 JA-001 |
| D、E、F | 交安工程、路面标线、安全设施。执行说明解析结果不同时改用说明 |
| G、H | 留空 |
| I 至 R | 留空。说明要求按源表填写，但当前台账没有这些属性列，不补造 |
| S 至 X | 不超过 2km 的两个导线点：点号、X、Y。小数 3 位 |
| Y、Z | 不超过 2km 的一个水准点：点号、高程。小数 3 位 |
| AA、AB | 起止桩号，取整到 10 的整数 |
| AC | 间距。见第六节 |
| AD、AE、AF | 2.2、0.1、0.01。执行说明中的「AD至AF列分别写上」能解析时改用说明 |
| AG | `=CONCATENATE("(",A行,")",B行,C行,E行)` |
| AH | 桩号前缀，如 K、AK、BK、CK |
| AI | `=CONCATENATE("(",A行,")",B行,C行,E行,"抽检")` |

B 列清洗与 JA-001 相同：词尾「左线」「右线」与「左侧」「右侧」同剥，清洗后的 B 列不保留这些字样。C 列仍可从台账中的「左线」「右线」推断左幅或右幅。

## 六、桩号间距

1. 起止桩号写成能被 10 整除的整数。
2. 范围长度小于等于 50m 时，AC 取 10。
3. 大于 50m 且小于等于 70m 时，AC 取 20。
4. 大于 70m 且小于等于 200m 时，AC 取 40。
5. 大于 200m 时，AC 取 100。
6. AB 与 AA 的差必须能被 AC 整除。不能整除时微调止桩号。
7. 只有一个桩号时，AA 和 AB 都写该桩号取整后的值，AC 写 0。
8. 没有桩号时，AA、AB、AC 留空。

这套分档只用于 JA-002。JA-001 和 JA-003 没有 100 这一档。

## 七、测站匹配

与 JA-001 相同。

邻近上限 2000m。只认全称：白岭互通、石坳互通、港口互通、修水西枢纽、铜鼓枢纽。

1. 有全称时只在该走廊池内选点。有桩号时不超过 2000m；池内不足则改用走廊主线 K 中位数，相对中位数仍不超过 2000m。
2. 无桩号但有全称时，用走廊主线 K 中位数在池内取点，不套 2000m。
3. 没有全称时走全局匹配，不超过 2000m。没有桩号则留空。
4. 不启用 3km 兜底。

缺 2 个导线点或缺水准点时，测站留空，整行黄底 `FFFF00`。

## 八、注意事项

| 编号 | 触发条件 | 级别 | 处理 |
|---|---|---|---|
| N-001 | 2km 内测站不足 | 警告 | 留空、标黄、写入缺测站清单 |
| N-002 | 说明要求填写 I 至 R，台账却没有属性列 | 提示 | 留空，并在报告中写明未补造 |
| N-003 | 无桩号且无互通全称 | 警告 | 不猜测位置 |
| N-004 | 放宽到 3km | 阻断 | 不启用 |

## 九、边界条件和易错点

- 标线台账里很多无桩号行不带互通全称，锁池救不回这些黄行。
- 匝道小桩号在不同互通重复。必须先锁全称，再比距离。
- AD、AE、AF 是说明给定的常量，不是从台账计算出来的。
