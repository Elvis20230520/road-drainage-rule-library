> 草稿。填表要求来自隔离栅、防落物网参数的执行说明。测站匹配与 JA-001 相同：互通只锁全称，邻近上限 2km。确认前不用于正式成果。`tools/ja_params` 目前只生成 JA-001、JA-002、JA-003，本编号还不能按吩咐直接出表。

## 一、目标

从资料台账生成「隔离栅、防落物网-JA-007」参数表。E 列按台账用词区分防落物网、防坠网，以及其他说明尚未定义的叫法。

## 二、适用范围

- 台账工作表按现有交安编号习惯为 `交安工程-JA-007`，有效内容在 B 列。执行说明没有另写表名。
- 参数样板工作表为 `隔离栅、防落物网-JA-007`。
- B 列已写明位置的隔离栅、防落物网、防坠网记录。

## 三、不适用范围

- 把说明未定义的叫法自行并进「防落物网」。
- 台账没有含水量、浇筑时间、砼数量、坍落度、混凝土编号、埋置深度时，用样板示例值补上。
- 与当前参数样板列结构不一致的表。
- 3km 测站兜底，以及用互通短名锁池。

## 五、与执行说明不一致的地方

1. 第 11 条定义的起止桩号和间距是 Z、AA、AB，单桩号也写 Z、AA、AB。同一句里「S 列减去 R 列的差值始终要被 T 列整除」沿用了别的表的列名。本表改为：AA 与 Z 的差必须能被 AB 整除。
2. 说明写 E 列为「防落物网」或者「防坠网」，自动识别。样板示例行里还有「隔离栅」「车行分道栅」「防垫网」。这些叫法的归并说明没有写，见第六节，确认前不并成防落物网。

## 六、填写规则

表头两行从样板复制。数据从第 3 行起写。不把样板里的示例数据行带入结果。

| 列 | 规则 |
|---|---|
| A | 序号，从 1 起 |
| B | 台账 B 列。去掉开头的「隔离栅、防落物网」；若紧跟着「工程」，一并去掉。再去掉末尾左右侧用语。词尾「左线」「右线」与「左侧」「右侧」同剥 |
| C | 左幅或右幅。规则同 JA-001 |
| D、F | 交安工程、安全设施 |
| E | 按台账用词识别。见下文 |
| G | 留空 |
| H 至 M | 留空。说明写按源表数据。含水量、浇筑时间、砼数量在当前台账读取范围里没有来源，不把样板示例抄进来 |
| N 至 S | 不超过 2km 的两个导线点：点号、X、Y。小数 3 位 |
| T、U | 不超过 2km 的一个水准点：点号、高程。小数 3 位 |
| V 至 Y | 留空。坍落度和基础混凝土编号同样没有台账来源，不补造 |
| Z、AA | 起止桩号，取整到 10 的整数 |
| AB | 间距。见第七节 |
| AC 至 AE | 留空 |
| AF | `=CONCATENATE("(",A行,")",B行,C行,E行)` |
| AG | 台账中出现的桩号前缀，如 K、AK、BK、CK |
| AH | 埋置深度。说明写按源表数据。台账没有时留空，不把样板示例中的 1.2 抄进每一行 |
| AI | `=CONCATENATE("(",A行,")",B行,C行,E行,"抽检")` |

E 列只看台账原文，不看清洗后的 B 列是否还剩这些词：

1. 出现「防坠网」时写防坠网。
2. 出现「防落物网」时写防落物网。
3. 两者都出现时，写文中先出现的一个，并在报告中注明。
4. 只出现「隔离栅」、没有前两词时，E 写「隔离栅」，报告注明。说明没有把隔离栅改写成防落物网。
5. 出现「车行分道栅」「防垫网」或其他说明没点名的叫法时，E 照台账用词填写，报告列出。不归并。
6. 以上都没有时，E 留空，报告注明。

B 列清洗与 JA-001 相同处理侧别：词尾「左线」「右线」与「左侧」「右侧」同剥。C 列仍可从台账中的「左线」「右线」推断左幅或右幅。

## 七、桩号间距

与 JA-001 的分档相同，列是 Z、AA、AB：

1. 起止桩号写成能被 10 整除的整数。
2. 范围长度小于等于 50m 时，AB 取 10。
3. 大于 50m 且小于等于 70m 时，AB 取 20。
4. 大于 70m 时，AB 取 40。
5. AA 与 Z 的差必须能被 AB 整除。不能整除时微调止桩号。
6. 只有一个桩号时，Z 和 AA 都写该桩号取整后的值，AB 写 0。
7. 没有桩号时，Z、AA、AB 留空。

这套分档没有 100。100 只用于 JA-002。说明里的 R、S、T 不用于本表。

## 八、测站匹配

与 JA-001 相同。

邻近上限 2000m。只认全称：白岭互通、石坳互通、港口互通、修水西枢纽、铜鼓枢纽。

1. 有全称时只在该走廊池内选点。有桩号时不超过 2000m；池内不足则改用走廊主线 K 中位数，相对中位数仍不超过 2000m。
2. 无桩号但有全称时，用中位数在池内取点，不套 2000m。
3. 没有全称时走全局匹配，不超过 2000m。
4. 不启用 3km 兜底。

缺测站的数据行整行黄底 `FFFF00`。

样板示例里的「阳明湖互通」不自动加入全称名单。

## 十、边界条件和易错点

- 本分项名称含隔离栅，E 列却不默认写成隔离栅或防落物网。没有对应用词时留空。
- 样板示例里的埋置深度 1.2、含水量和混凝土编号是示例，不是本规则的常量。
- AC、AD、AE 说明要求留空。不要把样板示例中的高度、高差、偏距抄进去。
- 匝道桩号必须先按互通全称锁池。锁池名单仍是 JA-001 那五个全称。
