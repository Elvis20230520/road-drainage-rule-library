> 草稿。填表要求来自管道工程参数的执行说明。测站匹配与 JA-001 相同：互通只锁全称，邻近上限 2km。确认前不用于正式成果。`tools/ja_params` 目前只生成 JA-001、JA-002、JA-003，本编号还不能按吩咐直接出表。

## 一、目标

从资料台账生成「管道工程-JA-005」参数表，写明位置、左右幅、桩号间距和测站。

## 二、适用范围

- 台账工作表按现有交安编号习惯为 `交安工程-JA-005`，有效内容在 B 列。执行说明没有另写表名。
- 参数样板工作表为 `管道工程-JA-005`。
- B 列已写明位置的管道工程记录。

## 三、不适用范围

- 把单桩号写进 AA、AB。说明末尾的列名是笔误，见第五节。
- 台账没有砼数量时，把样板示例中的数量抄到每一行。
- 与当前参数样板列结构不一致的表。
- 3km 测站兜底，以及用互通短名锁池。

## 五、与执行说明不一致的地方

说明第 10 条前面写 R、S、T，末尾又写成「只有一个桩号时 AA 和 AB 写上该桩号」。本表的起止桩号在 R、S，单桩号按 R=S、T=0 填写。不按末尾的笔误去填 AA、AB。

样板示例行 E 列已经是「管道工程」，与说明一致。生成时仍用说明里的「管道工程」，不要把示例行整行抄进来。

## 六、填写规则

表头两行从样板复制。数据从第 3 行起写。不把样板里的示例数据行带入结果。

| 列 | 规则 |
|---|---|
| A | 序号，从 1 起 |
| B | 台账 B 列。去掉开头的「管道工程」；若紧跟着「工程」，一并去掉。再去掉末尾左右侧用语。词尾「左线」「右线」与「左侧」「右侧」同剥 |
| C | 左幅或右幅。规则同 JA-001 |
| D、E、F | 交安工程、管道工程、安全设施。执行说明解析结果不同时改用说明 |
| G、H | 留空。说明点名 G 列留空。H 是施工时间，不从样板示例日期抄入 |
| I | 砼数量。说明写按源表数据。台账没有这一列时留空，不把样板示例数量抄进每一行 |
| J 至 O | 不超过 2km 的两个导线点：点号、X、Y。小数 3 位。没有桩号时留空 |
| P、Q | 不超过 2km 的一个水准点：点号、高程。小数 3 位。没有桩号时留空 |
| R、S | 起止桩号，取整到 10 的整数 |
| T | 间距。见第七节 |
| U 至 W | 留空 |
| X | 保留样板公式 `=CONCATENATE("(",A行,")",B行,C行,E行)` |
| Y | 台账中出现的桩号前缀，如 K、AK、BK、CK。没有桩号时写 K，不留空 |
| Z | 保留样板公式 `=CONCATENATE("(",A行,")",B行,C行,E行,"抽检")` |

B 列清洗与 JA-001 相同：词尾「左线」「右线」与「左侧」「右侧」同剥，清洗后的 B 列不保留这些字样，也不保留开头的「管道工程」。C 列仍可从台账中的「左线」「右线」推断左幅或右幅。

## 七、桩号间距

与 JA-001 的分档相同，列是 R、S、T：

1. 起止桩号取整到 10。
2. 范围长度小于等于 50m 时，T 取 10。
3. 大于 50m 且小于等于 70m 时，T 取 20。
4. 大于 70m 时，T 取 40。
5. S 与 R 的差必须能被 T 整除。不能整除时微调止桩号。
6. 只有一个桩号时，R 和 S 都写该桩号取整后的值，T 写 0。不按说明末尾的笔误去填 AA、AB。
7. 没有桩号时，R、S、T 留空。

这套分档没有 100。100 只用于 JA-002。

## 八、测站匹配

与 JA-001 相同。

邻近上限 2000m。只认全称：白岭互通、石坳互通、港口互通、修水西枢纽、铜鼓枢纽。

1. 有全称时只在该走廊池内选点。有桩号时不超过 2000m；池内不足则改用走廊主线 K 中位数，相对中位数仍不超过 2000m。
2. 无桩号但有全称时，用中位数在池内取点，不套 2000m。
3. 没有全称时走全局匹配，不超过 2000m。没有桩号则测站留空。
4. 不启用 3km 兜底。

缺测站的数据行整行黄底 `FFFF00`。

说明里的「无桩号则测站留空」，按上面第 3 条执行：没有互通全称时留空。有全称时仍用走廊中位数补测站。

## 十、边界条件和易错点

- 样板示例行里的间距有 80、100、200，那是示例，不作为本规则的分档。
- 匝道桩号必须先按互通全称锁池。
- I 列不要用里程长度代替砼数量。U、V、W 按说明留空，不抄样板示例里的高度、高差和偏距。
- 没有桩号时 Y 仍写 K。不要把这一格留空，也不要抄样板示例里的 YK。
