> 草稿。内容来自交通标志参数的执行说明，以及已跑通的测站匹配：互通走廊只锁全称，邻近上限 2km。确认前不用于正式成果。

## 一、目标

从资料台账生成「标志牌-JA-001」参数表。每条记录保留位置、左右幅、桩号间距和可追溯的测站；缺测站的行要看得出来。

## 二、适用范围

- 台账工作表为 `交安工程-JA-001`，有效内容在 B 列。
- 参数样板工作表为 `标志牌-JA-001`。
- 主线、左右幅、匝道、互通和枢纽，只要 B 列能读出位置描述。

## 三、不适用范围

- 台账没有写明、需要另行设计判断的标志内容。
- 与当前参数样板列结构不一致的表。
- 把 2km 放宽到 3km 的匹配。本规则不启用该兜底。
- 用短名（如「白岭」「修水西」）猜测互通。

## 五、填写规则

表头两行从样板复制。数据从第 3 行起写。样板 A1 里的数字是样板自带的，生成时不改表头。

| 列 | 规则 |
|---|---|
| A | 序号，从 1 起 |
| B | 台账 B 列。去掉开头的「标志工程」，并去掉末尾左右侧用语 |
| C | 左幅或右幅。明确写左侧、右侧时直接采用；只能推断时仍填写，并在报告中注明 |
| D、E、F | 交安工程、交通标志、交通标志。执行说明里解析出不同写法时，改用说明 |
| G 至 M | 留空 |
| N 至 S | 桩号附近不超过 2km 的两个导线点：点号、X、Y。小数 3 位 |
| T、U | 不超过 2km 的一个水准点：点号、高程。小数 3 位 |
| V 至 Y | 留空 |
| Z、AA | 起止桩号，取整到 10 的整数 |
| AB | 间距。见第六节 |
| AC 至 AE | 留空 |
| AF | `=CONCATENATE("(",A行,")",B行,C行,E行)` |
| AG | 台账中出现的桩号前缀，如 K、AK、BK、CK |
| AH 至 AL | 留空 |
| AM | `=CONCATENATE("(",A行,")",B行,C行,E行,"抽检")` |

B 列清洗只去掉工程前缀和侧别用语，不改写构造名称。

左右幅：优先认「路线右侧 / 左侧」「匝道右侧 / 左侧」等完整说法。没有这些说法时，靠后出现的「右」或「左」用于推断。中央分隔带、中分带且没有左右字样时取左幅，并在报告中标为推断。完全没有左右信息时 C 列留空。

## 六、桩号间距

1. 起止桩号写成能被 10 整除的整数。
2. 原始范围长度小于等于 50m 时，AB 取 10。
3. 大于 50m 且小于等于 70m 时，AB 取 20。
4. 大于 70m 时，AB 取 40。
5. AA 与 Z 的差必须能被 AB 整除。不能整除时微调止桩号。
6. 只有一个桩号时，Z 和 AA 都写该桩号取整后的值，AB 写 0。
7. 没有桩号时，Z、AA、AB 留空。

台账里的 `~`、`-` 只作分隔。桩号本身按 `K`、`AK`、`BK`、`CK` 等形式识别。

## 七、测站匹配

邻近上限为 2000m。互通只认下列全称，位置描述里出现即算该走廊：

- 白岭互通
- 石坳互通
- 港口互通
- 修水西枢纽
- 铜鼓枢纽

「辐射整个××」因为含有全称，进入同一池。不要用「白岭大桥」一类短名锁池。

1. B 列有上述全称时，导线点和水准点只从位置描述含该全称的池里选。
2. 有桩号：池内先同前缀，不够再池内任意前缀，距离不超过 2000m。仍不够，且池内至少有 2 个导线点和 1 个水准点时，改用该走廊主线 K 桩号的中位数作目标，距离相对中位数仍不超过 2000m。
3. 无桩号但有全称：用走廊主线 K 中位数作目标，在池内取最近的 2 个导线点和 1 个水准点，不套 2000m。池太小则测站留空。
4. B 列没有全称：在全部测站中同前缀优先，再任意前缀，不超过 2000m。没有桩号则测站留空。
5. 两个导线点不能是同一条测站记录。
6. 不因为主线测站稀疏而放宽到 3km。

目标桩号：两个桩号取中点，一个桩号取该桩号。

缺 2 个导线点或缺水准点时，对应单元格留空，该数据行整行黄底 `FFFF00`，并写入缺测站清单。

## 八、注意事项

| 编号 | 触发条件 | 级别 | 处理 |
|---|---|---|---|
| N-001 | 2km 内导线点少于 2 个或没有水准点 | 警告 | 测站留空，整行标黄，写入缺测站清单 |
| N-002 | 无桩号且无互通全称 | 警告 | 不猜测位置，整行标黄 |
| N-003 | 左右幅只能推断或无法判定 | 提示 | C 列按规则填写或留空，报告列出样例 |
| N-004 | 想用 3km 补上隧道段或终点附近的空洞 | 阻断 | 本规则不启用。先补测站或单独立项 |
| N-005 | 执行说明与样板表名不一致 | 提示 | 以样板工作表「标志牌-JA-001」和输出文件名为准 |

## 九、边界条件和易错点

- 不同互通会重复使用 AK、CK 等小桩号。不锁走廊时，白岭互通的 AK 可能配到石坳互通的测站。
- 无桩号但写了互通全称的行，靠走廊中位数补测站，这是推断，不是现场桩号。
- 主线测站覆盖不到的路段会保持黄行。这是测站空洞，不是前缀偏好造成的。
- 表头从样板复制，不把样板里的示例数据行带入结果。

- 重跑时给出规则库、「按编号 JA-001 去执行，项目编号〈当次编号〉」，以及本机上该次台账和导线点及水准点所在的路径。

- 确认没有使用超过 2000m 的全局匹配，也没有 3km 兜底。
