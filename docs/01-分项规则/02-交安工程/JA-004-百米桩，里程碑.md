> 草稿。填表要求来自百米桩、里程碑参数的执行说明。测站匹配与 JA-001 相同：互通只锁全称，邻近上限 2km。确认前不用于正式成果。`tools/ja_params` 目前只生成 JA-001、JA-002、JA-003，本编号还不能按吩咐直接出表。

## 一、目标

从资料台账生成「百米桩，里程碑-JA004」参数表。工作表名和输出文件名都用这个写法：中文逗号，编号是 `JA004`，没有连字符。

## 二、适用范围

- 台账工作表按现有交安编号习惯为 `交安工程-JA-004`，有效内容在 B 列。执行说明没有另写表名。
- 参数样板工作表为 `百米桩，里程碑-JA004`。
- 主线、左右幅中，B 列已写明位置的百米桩、里程碑记录。台账若把公路界碑写在同一条位置描述里，位置文字留在 B 列，不另分一个编号。

## 三、不适用范围

- 把工作表或输出文件改成「百米桩，里程碑-JA-004」。说明和样板都没有这个连字符。
- 用样板示例行里的间距（20、80、200、300、400、600）代替说明里的 500。
- 台账没有砼数量时，把样板示例中的数量抄到每一行。
- 与当前参数样板列结构不一致的表。
- 3km 测站兜底，以及用互通短名锁池。

## 五、与执行说明、样板示例不一致的地方

1. 规则编号是 JA-004。样板工作表和输出文件名按说明写作「百米桩，里程碑-JA004」，不要自行补上连字符。
2. 说明要求 E 列写「百米桩，里程碑」。样板示例行 E 列写的是「里程碑和百米桩」。生成时用说明里的写法。
3. 说明写 T 列一般为 500。样板示例行里的间距不是 500。生成时不抄那些示例间距。
4. 说明没有写「S 与 R 的差必须能被 T 整除」，也没有写只有一个桩号时怎么填。这两处见第六节，先标待确认，不套 JA-006 的 10/20/40。

## 六、填写规则

表头两行从样板复制。数据从第 3 行起写。样板 A1 里的数字是样板自带的，生成时不改表头。不把样板里的示例数据行带入结果。

| 列 | 规则 |
|---|---|
| A | 序号，从 1 起 |
| B | 台账 B 列。去掉开头的「百米桩，里程碑工程」和末尾左右侧用语。词尾「左线」「右线」与「左侧」「右侧」同剥 |
| C | 左幅或右幅。规则同 JA-001 |
| D、E、F | 交安工程、百米桩，里程碑、安全设施。执行说明解析出不同写法时，改用说明 |
| G、H | 留空。说明点名 G 列留空。H 是施工时间，不从样板示例日期抄入 |
| I | 砼数量。说明写按源表数据。台账没有这一列时留空，不把样板示例数量抄进每一行 |
| J 至 O | 桩号附近不超过 2km 的两个导线点：点号、X、Y。小数 3 位 |
| P、Q | 不超过 2km 的一个水准点：点号、高程。小数 3 位 |
| R、S | 起止桩号，取整到能被 10 整除的整数 |
| T | 间距。见第七节 |
| U 至 W | 留空 |
| X | `=CONCATENATE("(",A行,")",B行,C行,E行)` |
| Y | 台账中出现的桩号前缀，如 K、AK、BK、CK |
| Z、AA、AB | 保留样板源表数据，不从台账改写。见第八节 |
| AC | `=CONCATENATE("(",A行,")",B行,C行,E行,"抽检")` |

B 列清洗只去掉工程前缀和侧别用语，不改写构造名称。位置描述中间的「百米桩」「里程碑」「公路界碑」仍留在 B 列。

左右幅与 JA-001 相同。中央分隔带、中分带且没有左右字样时取左幅，并在报告中标为推断。完全没有左右信息时 C 列留空。

## 七、桩号间距

说明只规定到这一步：

1. R、S 写成能被 10 整除的整数。
2. T 一般为 500。
3. 没有桩号时，R、S、T 留空，不要为了填 500 去编一个区间。

说明没有写分档，本规则不使用 JA-001、JA-006 的 10/20/40，也不使用 JA-002 的 100。

下列情况说明没有写处理办法，生成时不要另造一套间距：

- 区间长度不能被 500 整除。T 仍写 500，该行在报告中注明待确认。
- 只有一个桩号。R、S 都写该桩号取整到 10 后的值，T 仍写 500，并在报告中注明。确认前不改成 T=0。

## 八、外形尺寸

Z、AA、AB 是样板里的外形尺寸：高度、宽度、厚度。说明要求保留样板源表数据。

当前 `百米桩，里程碑-JA004` 各示例行这三列都是 1000、120、100。生成时每行写入样板里的这三个数。样板以后改了数，跟样板走，不跟本页里的举例。

## 九、测站匹配

与 JA-001 相同。

邻近上限 2000m。只认全称：白岭互通、石坳互通、港口互通、修水西枢纽、铜鼓枢纽。

1. 有全称时只在该走廊池内选点。有桩号时不超过 2000m；池内不足则改用走廊主线 K 中位数，相对中位数仍不超过 2000m。
2. 无桩号但有全称时，用走廊主线 K 中位数在池内取点，不套 2000m。
3. 没有全称时走全局匹配，不超过 2000m。没有桩号则测站留空。
4. 两个导线点不能是同一条测站记录。
5. 不启用 3km 兜底。

缺 2 个导线点或缺水准点时，对应单元格留空，该数据行整行黄底 `FFFF00`，并写入缺测站清单。

样板示例里的「阳明湖互通」一类地名不自动加入上面的全称名单。

## 十一、边界条件和易错点

- 样板示例行是以前填过的例子，间距、施工日期、砼数量都不要整行抄进结果。
- 匝道小桩号在不同互通重复。必须先锁全称，再比距离。锁池名单仍是 JA-001 那五个全称。
- Z、AA、AB 是样板常量。I 列不是。不要用里程长度代替砼数量。
- 表头从样板复制，不把样板里的示例数据行带入结果。
