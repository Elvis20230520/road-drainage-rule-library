# 分项规则库

本库用于统一管理分项规则、必要文件、业务认知、注意事项、案例和输出要求。

## 如何查找规则

1. 在[分项总表](分项总表.csv)中按编号、名称、分类或关键词查找。
2. 打开总表中“规则文件”列对应的文件。
3. 确认规则状态为“正式”，并核对版本和生效日期。
4. 再读取对应项目的注意事项。

## 规则状态

| 状态 | 含义 | 是否可用于正式任务 |
|---|---|---|
| 草稿 | 正在整理或待确认 | 否 |
| 正式 | 已确认并生效 | 是 |
| 停用 | 已失效或已被替代 | 否 |

## 认知成熟度

| 等级 | 内容要求 |
|---|---|
| L1 | 有基本操作规则 |
| L2 | 有判断条件和计算逻辑 |
| L3 | 有边界条件、注意事项和易错点 |
| L4 | 有正例、反例和特殊案例 |
| L5 | 有完整测试案例和结果验证 |

认知成熟度表示知识完整程度，不代表规则是否正式生效。

## 使用原则

- 不使用草稿或停用规则处理正式成果。
- 不用历史案例替代当前项目资料。
- 缺少必要文件时，先列出缺失项，不静默假设。
- 每次成果应记录分项编号、规则版本和使用日期。
- 规则、项目要求和强制性依据冲突时，停止执行并明确列出冲突。
