# 分项规则库

本库用于统一管理分项规则、必要文件、业务认知、注意事项、案例和输出要求。

## 如何查找规则

1. 在[分项总表](分项总表.csv)中按编号、名称、分类或关键词查找。
2. 打开总表中“规则文件”列对应的文件。
3. 确认规则状态为“正式”，并核对版本和生效日期。
4. 再读取对应项目的注意事项。

## 规则状态

| 状态 | 含义 | 是否可用于正式任务 |
|---|---|---|
| 草稿 | 正在整理或待确认 | 否 |
| 正式 | 已确认并生效 | 是 |
| 停用 | 已失效或已被替代 | 否 |

## 认知成熟度

| 等级 | 内容要求 |
|---|---|
| L1 | 有基本操作规则 |
| L2 | 有判断条件和计算逻辑 |
| L3 | 有边界条件、注意事项和易错点 |
| L4 | 有正例、反例和特殊案例 |
| L5 | 有完整测试案例和结果验证 |

认知成熟度表示知识完整程度，不代表规则是否正式生效。

## 使用原则

- 不使用草稿或停用规则处理正式成果。
- 不用历史案例替代当前项目资料。
- 缺少必要文件时，先列出缺失项，不静默假设。
- 每次成果应记录分项编号、规则版本和使用日期。
- 规则、项目要求和强制性依据冲突时，停止执行并明确列出冲突。

## 交安参数

JA-001、JA-002、JA-003、JA-004、JA-006、JA-007 的草稿在[分项规则](01-分项规则/02-交安工程/index.md)。编号不是连号，没有 JA-005。生成参数表时给出三件事：规则库地址（或本机已 clone 的仓库）、吩咐「按编号 JA-001 去执行，项目编号 001」、本机必要文件路径。路径每次单独指定。多个编号写成「按编号 JA-001、JA-002、JA-003 去执行，项目编号 001」。参数样板只有 `share/参数样板.xlsx` 一份，现为七张表；指定路径里有同名文件时先用那一份。该路径放台账和导线点及水准点，结果留在其中的 `output/`。填表以各编号的资料参数执行说明为准。说明要求看图纸时读图；缺图先列缺项，不臆造。这六条现行说明以台账、测点和样板为主。`tools/ja_params` 目前只生成 JA-001、JA-002、JA-003。`share/ja-params-sample-001/` 只示范这三份的布局。说明见 `tools/ja_params/README.md`。
